# Celia · ELA 20-1 learning space

Public learner-facing site for one ELA 20-1 course (GitHub Pages). It holds the navigation shell, the homework and
notebook pages and their scripts. Class handouts, homework items, drafts, submissions and feedback live in a private
service and appear only after the website password is entered.

- `index.html` — learning home, newest class first.
- `YYYY-MM-DD/` — one folder per class: `index.html` (links), `handout.html` (protected handout loader), `hm*.html` (homework).
- `notebook/` — a server-backed notebook for planning and free writing.
- `assets/` — shared stylesheet and scripts.

No answer keys, teacher notes, learner records or private paths are stored in this repository.
